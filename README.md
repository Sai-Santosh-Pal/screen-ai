# ScreenAI

A screen tracker AI which tracks what you really do!

- Uses Hack Club AI API
- Download from Releases tab
- No API key needed! Download it and you are good to go!
- Open the application and keep it up and running while you do your work
- For the dashboard, go to the URL which the console shows

## What's it?
- Tracks what you exactly do!
- It shows you what are you exactly doing instead of the app you're on
- A general screen time tracker would track what app you're on, and not what you're doing inside it
- For eg. If you're doomscrolling or learning from youtube it's the same tracking while if you use this - it seperates it!!

## How to Use?
- Download the application and open it
- Make sure the console is up and running because it tracks what you're doing
- Then, to see the dashboard - visit the link that's mentioned in the console!
- You could see details and a chart of what you're doing
- p.s - on the first run, you must use some applications for 1-2 minutes to see the charts and other things
